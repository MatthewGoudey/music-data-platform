# ADR 0011: Depth-goal vocabulary

- Status: Accepted (recommendation; change by editing this file)
- Date: 2026-10-07
- Decision: Adopt the V Album Atlas vocabulary

Layer (era), Zone (Core / V / Context), Lane with parent lanes, Priority (Essential / Recommended / Deep cut), Start here, Scene, Label and Tags become the system's vocabulary for the home genre. The atlas workbook loads as seven CSVs in `seeds/atlas/`; its Heard, Rating and Notes columns are never filled in the sheet.
