# ADR 0014: Tag vocabulary and verdict words

- Status: Proposed
- Date: 2026-10-07
- Decision: Six tags; again / later / never

Context tags start as study, workout, cooking, with-people, rainy, morning, attached to release groups and drawn from this list only. Verdicts are the three words again / later / never; a 1 to 5 rating is optional and added only if it will be used.
