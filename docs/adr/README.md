# Architecture decision records

One short file per decision. A decision is changed by editing its file and noting why, not by
rewriting history. New ADRs take the next number.

Template:

```
# ADR NNNN: <title>

- Status: Proposed | Accepted | Superseded by ADR NNNN
- Date: YYYY-MM-DD
- Decision: <one line>

<context, the decision, the alternatives considered, consequences>
```
