# Seeds

Reference data committed to the repo and loaded by jobs. Nothing here is personal listening data.

- `lists/` — published lists as CSV (Rolling Stone 500, 1001 Albums, AOTY years). Phase 4.
- `atlas/` — the V Album Atlas as seven CSVs: albums, artists, lanes, scenes, labels, tags, paths. Phase 4.
- `canon_export.csv` — the Claude-curated canon exported from the old database. Phase 4.
- `venues.csv` — the 268 Chicago venues with travel times from the old database. Phase 3.
- `manual_tracklists.csv` — hand-set track counts for albums MusicBrainz and Last.fm lack. Phase 2.
- `festivals/` — one CSV per festival lineup. Phase 3.
